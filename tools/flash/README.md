# flash

GitHub Actions でビルドされた roBa のファームウェアを取ってきて、XIAO に書き込むツールです。
Actions のページから zip をダウンロードし、展開し、ドライブにコピーする作業を、これ1つで済ませます。

## 必要なもの

- Python（`py` ランチャー）と GitHub CLI（`gh`、ログイン済み）。どちらもこの PC には入っています。
- 追加のライブラリは要りません。`setup` も不要です。

## 使い方

`flash.cmd` をダブルクリックするか、ターミナルで実行します。

1. 使うビルドが表示され、ファームウェアをダウンロードします（2回目からは保存済みのものを使います）。
2. 「どちらに書き込みますか？」と聞かれるので、番号を入れます。
   - 1：両方（右手 → 左手の順）
   - 2：右手だけ
   - 3：左手だけ
3. 「〇〇を USB で PC につなぎ、ブートローダーに入れてください」と出たら、その側をブートローダーにします。
   - XIAO のリセットボタンを素早く2回押す
   - または SYS レイヤー（L1+L2）の bootloader キーを押す（PR #2 以降のキーマップ）
4. ドライブが現れると自動で書き込み、XIAO が再起動します。両方のときは、続けてもう片方を同じように行います。

USB ケーブルが1本しかなければ、右手が終わったら左手につなぎ替えてください。

## どのビルドを使うか

- 何も指定しないと、**今チェックアウトしているブランチ**の最新の成功ビルドを使います。そのブランチにビルドがなければ `main` を使います。
- 別のブランチを使うとき：
  ```
  flash.cmd both --branch keymap/keyball44-port
  ```
- 最近の成功ビルドを見るとき：`flash.cmd --list`
- ビルド番号で指定するとき：`flash.cmd both --run 40658132391`
- ダウンロードだけするとき：`flash.cmd --download-only`

もっと新しいビルドが実行中か、失敗しているときは `[注意]` を表示します。そのときは1つ前の成功ビルドを書き込むことになるので、必要ならビルドが終わってからやり直してください。

ダウンロードしたファームウェアは `data/firmware/<ビルド番号>/` に保存されます（git の管理外）。

## ペアリング情報を消す（settings_reset）

```
flash.cmd both --settings-reset
```

左右に `settings_reset` を書き込みます。**ペアリング情報が消える**ので、実行前に確認を求めます。
終わったら、通常のファームウェアを書き直して（`flash.cmd both`）、左右と PC のペアリングをやり直してください。

## 安全のための動き

- 書き込み先は、`INFO_UF2.TXT` がある取り外し可能ドライブだけです。中身に nRF52840 と書かれていなければ、確認を求めます。
- ブートローダーのドライブが複数あるときは書き込みません。1台ずつ接続してください。
- 書き込み後、ドライブが消える（XIAO が再起動する）のを確かめてから次に進みます。
